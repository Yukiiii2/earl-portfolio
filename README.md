# Earl Ang | Developer Portfolio

A developer portfolio built with Vue 3, Vite, and Tailwind CSS. It features a custom 3D hero section, cinematic dark mode with glassmorphism effects, dynamic mouse spotlight interactions, and a fully functional contact form.

## 🚀 Tech Stack & Tools

* **Framework:** Vue 3 (Composition API)
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Typography:** [Outfit](https://fonts.google.com/specimen/Outfit) (Google Fonts)
* **Animations:** AOS (Animate On Scroll) & Custom CSS Keyframes
* **Contact Form Backend:** [Formspree](https://formspree.io/)
* **Hosting/Deployment:** Vercel
* **Version Control:** Git & GitHub

## ✨ Key Features

* **Cinematic UI:** Ambient background glows, film grain overlay, and glassmorphism cards.
* **Interactive Spotlight:** Custom JS/CSS mouse-tracking glow effect on project and skill cards.
* **Infinite Marquee:** CSS-animated infinite scrolling ticker for services and capabilities.
* **Functional Contact Form:** Direct-to-inbox messaging without backend servers.
* **Responsive Design:** Mobile-first architecture with a custom slide-out hamburger menu.
